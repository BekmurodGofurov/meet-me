# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Meet-Me seriously. If you discover a security vulnerability, please do not disclose it publicly via GitHub Issues.

### Reporting Process

1. Email your findings to **bekmurod@bekmurod.uz** (or contact the maintainer via GitHub profile).
2. Include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact of the issue.
3. You will receive an acknowledgment within 48 hours.
4. We will work to resolve the issue promptly before any public disclosure.
